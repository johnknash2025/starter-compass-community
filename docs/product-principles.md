# プロダクト原則

最終更新: 2026-10-01

## 利用者の課題についての仮説

個人事業を続けるか法人を設立するかの判断では、税額だけでは結論が出ない場合があります。収益モデル、必要経費、本人への報酬、社会保険、自治体、家族・雇用の条件、設立後に法人へ残す資金などの前提を組み合わせて検討する必要があります。

Starter Compass は、複数の条件を並べて見渡す作業を支援することを目指します。どのケースが実際に多いか、誰が対価を払うかは、利用者・専門家への調査で確かめる必要があります。

## 設計原則

1. **結論を断定しない** — 「法人化すべき」と表示せず、入力した前提に対する比較と感度を示す。
2. **比較単位を混ぜない** — 個人の手取り、法人に残る資金、税・社会保険、法人維持コストを分けて示す。
3. **前提を追跡できる** — 適用年度、地域、根拠URL、確認日、計算の丸め、対象外の条件を表示する。
4. **未確認を隠さない** — 推測値を制度上の確定値のように使わない。未確認ケースは除外または明示的な仮置きとして扱う。
5. **プライバシーを基本にする** — 現行アプリでは入力値をブラウザ内で処理し、サーバー送信・保存・解析をしない。将来仕様を変える場合は、事前に目的・範囲・保持期間を説明して選択を得る。
6. **人による確認を助ける** — 税理士・社会保険労務士等へ相談するときに、比較した条件と疑問点を整理できるようにする。
7. **AIを業種ラベルにしない** — AI関連事業は法的な法人類型ではなく、提供内容・収益・費用構造に基づく検討ケースとして整理する。

## 期待する利用の流れ

1. 収益源、利益、働き方、地域などの前提を設定する。
2. 個人事業・法人・複合ケースを同じ条件で比較する。
3. 手取りや法人内留保だけでなく、税目・社会保険・固定費の差を確認する。
4. 前提や制度上の確認点を持って、必要に応じて専門家へ相談する。

## 対象外として扱うもの

- 税務・法律・社会保険に関する個別助言、税務代理、税務書類の作成。
- 税額・保険料・融資・補助金の結果を保証すること。
- 利用者の状況を十分に確認せず、単一の売上額だけで法人化の正解を示すこと。
- AIという名称だけを理由に、特別な税務上の取扱いがあると示すこと。
