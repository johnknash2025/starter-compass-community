# 公式情報の出典方針

最終更新: 2026-10-01

税・社会保険の実装根拠は、公的機関が公開する現行の一次資料を優先します。検索結果の抜粋や民間解説だけを制度値の根拠にしません。民間の解説は利用者の質問や論点を見つける補助として扱います。

## 主な確認先

| 分野 | 主な公式情報源 | 用途 |
|---|---|---|
| 国税 | [国税庁「税について調べる」](https://www.nta.go.jp/taxes/shiraberu/) / [タックスアンサー](https://www.nta.go.jp/taxes/shiraberu/taxanswer/index2.htm) | 所得税、法人税、消費税、源泉徴収、申告手続、改正情報 |
| 厚生年金 | [日本年金機構「厚生年金保険の保険料」](https://www.nenkin.go.jp/service/kounen/hokenryo/hoshu/20150515-01.html) | 標準報酬月額、報酬の範囲、保険料の仕組み |
| 健康保険 | [協会けんぽ「保険料率」](https://www.kyoukaikenpo.or.jp/about/business/insurance_rate/index.html) | 都道府県別料率、年度ごとの保険料額表 |
| 農業法人 | [農林水産省「法人の設立手続」](https://www.maff.go.jp/j/kobetu_ninaite/n_seido/seturitu_tetuzuki.html) / [農事組合法人](https://www.maff.go.jp/j/keiei/sosiki/kyosoka/k_sido/kumiai/index.html) | 組織・設立・農業関連制度の論点 |
| 地方税 | 各都道府県・市区町村の税務担当部署 | 法人住民税均等割、超過課税、個人事業税等の地域差 |
| 法令 | [e-Gov法令検索](https://elaws.e-gov.go.jp/) | 法令条文・改正履歴の確認 |

## 確認記録

制度値を実装するときは、ソース内コメントだけに根拠を閉じ込めず、公開できる形で確認記録を保ちます。最低限、資料名、URL、確認日、適用年度、該当箇所、実装者、レビュー状態、次回確認時期を記録します。

公式ページに改正予告や適用開始日がある場合、資料の掲載日・施行日・実際の適用年度を区別します。別の年度の料率を流用した場合は、その差を明記して計算結果の対象範囲を限定します。

## 第三者資料と引用

公開文書では第三者資料を必要以上に複製しません。短い説明を自分の言葉でまとめて出典へリンクし、図表・文章・データの再利用は元資料の利用条件を確認します。法令や公的情報でも、出典表示や掲載形式に関する提供元の条件を確認します。
