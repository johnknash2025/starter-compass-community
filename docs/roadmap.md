# ロードマップと状態

最終更新: 2026-10-01

このロードマップは公開議論用です。日付や機能を約束するものではありません。利用者の課題、専門家レビュー、公式制度資料の確認に応じて順番を変えます。

## 今回の公開範囲

- プロダクト原則、候補シナリオ、計算透明性、公式出典方針を公開。
- Issue・Discussionで業種、ケース、用語、UIに関する意見を募集。
- 実装・検証済みと、候補・未確認を文書上で区別。
- 有料機能や有料プランは今回追加しない。

## 次に検証したいテーマ

1. 独立前後の給与・事業所得を含む、個人と一人法人の比較。
2. 受託、SaaS、AIエージェント、ローカル推論等のAI関連事業モデル。
3. 農業と受託業など複数事業を営む場合の制度分類・入力方法。
4. 都道府県・市区町村差、役員報酬、社会保険、法人内留保の表示。
5. 利用者が専門家へ相談する際に必要な前提・未確認項目の整理。

## 公開時点で約束しないもの

- 上記シナリオの網羅的な自動計算。
- 税理士・社会保険労務士の確認を経た個別ケース対応。
- 申告・会計・給与計算の作成や外部サービス連携。
- 有料化、価格、提供開始時期。
- 数字の正確性や、特定の選択肢が有利になるという保証。

## 優先順位の決め方

提案は、対象者、発生頻度、現在の代替手段、間違えた場合の影響、一次情報の有無、専門家レビューの要否、操作の負担を見て検討します。関心表明だけで需要確定とはみなしません。
