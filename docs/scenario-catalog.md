# シナリオカタログ

最終更新: 2026-10-01

このカタログは将来検討したいケースの一覧です。**列挙しただけで、実装済み・税務上の取扱い確認済みという意味ではありません。** 税務区分や制度適用が個別事情に依存するものは、専門家レビューまで計算対象にしません。

## 1. 働き方・収入の移行

| ケース | 比較したい条件 |
|---|---|
| 独立前後 | 給与所得と事業収入の併存期間、独立時期、事業初年度 |
| 副業から専業へ | 雇用給与、事業利益、複数の収益源、社会保険の加入状況 |
| 個人事業継続 | 青色申告等の前提、事業利益、事業税の業種判定 |
| 法人設立 | 役員報酬、会社負担社会保険料、法人固定費、内部留保 |
| 個人事業と法人の併営 | 事業ごとの主体、契約・資産・費用の帰属。適法性・税務取扱いは専門家確認が必要 |

## 2. 業種・収益モデル

これらは比較のための事業モデル分類であり、税法上の業種判定を置き換えるものではありません。

| 事業モデル | 将来検討する収益・費用項目 | 要確認事項の例 |
|---|---|---|
| ソフトウェア開発・IT受託 | 準委任・請負、外注、クラウド、開発端末 | 契約実態、事業税の法定業種 |
| 専門職・コンサルティング | 顧問・プロジェクト報酬、旅費、専門サービス | 報酬の性質、複数事業の区分 |
| クリエイター・デジタル商品 | 制作受託、ライセンス、広告、販売手数料 | 著作権・源泉徴収・消費税等 |
| 農業・農産物 | 生産物販売、加工、直売、農作業受託、設備・資材 | 農業法人・農事組合法人の制度、事業税区分、補助制度 |
| 小売・EC | 商品販売、在庫、決済手数料、配送 | 軽減税率・インボイス等、商品別の取扱い |
| 教育・研修 | 研修、講座、教材、個別支援 | 提供内容による税区分、契約形態 |
| AI導入支援・受託 | 導入支援、開発、保守、利用料 | 受託・ライセンスの契約と収益認識 |
| AI SaaS・エージェント | 定額課金、従量課金、モデル/API費、監視・運用費 | サービス提供地、契約・利用規約、データ管理 |
| ローカルAI・計算設備 | GPU・サーバー購入やリース、電力、保守、推論受託 | 固定資産・減価償却・リース等の個別判定 |
| AIコンテンツ・メディア | 広告、会員、ライセンス、制作受託 | 権利、生成物の利用条件、販売先 |
| AI教育・研修 | 法人研修、教材、講座、コミュニティ | 提供範囲、売上・経費の実態 |

## 3. AI事業を比較する軸

「AI法人」は本プロジェクト内の便宜的な呼び方であり、法律上の法人形態ではありません。少なくとも次を区別してケースを作ります。

- **AIを使う受託事業:** 人の役務が中心か、ソフトウェア・利用権の提供が中心か。
- **AIソフトウェア事業:** SaaS、API、エージェント、ライセンスなどの課金方法。
- **計算基盤を運営する事業:** クラウド従量費と自社設備の購入・リース・保守。
- **生成コンテンツ事業:** 制作受託、広告、会員、権利許諾。
- **AI教育・導入支援:** 研修、導入、運用改善、保守。

AI API利用料、ローカル推論設備、学習・評価データ、ソフトウェアライセンス、研究開発費などは、将来の費用項目候補です。損金算入や資産計上を自動判定する機能は未実装・未確認です。

## 4. 法人・組織の比較候補

- 個人事業主。
- 株式会社。
- 合同会社。
- 農事組合法人など農業に関わる組織形態。
- 役員一人の法人、家族役員を含む法人、従業員を雇用する法人。

組織形態ごとに設立・維持・会計・社会保険・農地等の制約は異なります。名称だけで税率や有利不利を決めず、対象年度・要件・一次情報を確認してから実装します。

## 5. 横断的な条件

- 都道府県、市区町村、事業所所在地。
- 事業年度、設立月、開業・廃業の時期。
- 年間売上、売上原価、経費、利益の季節変動。
- 役員報酬、賞与の有無、法人内に残す資金。
- 年齢区分、健康保険の加入先、標準報酬月額、扶養・家族条件。
- 雇用給与・年金・複数事業所などの他の所得・加入条件。
- 消費税の基準期間、特定期間、インボイス登録、課税方式。
- 資本金、従業者数、事務所数、自治体の税率・均等割。
- 固定費、税理士費用、設立費用、会計・給与・AI利用費。
- 退職金、社宅、配当、赤字繰越等の有無（複雑なケースは段階的に追加）。
