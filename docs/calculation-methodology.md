# 計算の透明性とレビュー方針

最終更新: 2026-10-01

## 表示する項目

比較画面・結果資料では、少なくとも次を区別して表示します。

- 個人の税引後手取り。
- 個人が負担する社会保険料。
- 法人が負担する社会保険料。
- 法人税・地方税等の税目別概算。
- 法人の維持費と利用者が入力した固定費。
- 税引後に法人内へ残る資金。
- 個人・法人を合わせた手元資金の見方（単純合算とその意味を明示）。
- 計算対象外の費目、適用条件、年度・地域・確認日。

「手取り」は一意な指標ではありません。給与として受け取った金額、個人の納税後の金額、法人に残した資金は別指標にし、法人内の資金を個人が自由に使えるお金として扱いません。

## シナリオの比較契約

比較するシナリオには、共通条件とシナリオ固有条件を記録します。共通条件には対象年度、所得・売上の期間、居住地・事業所、家族・扶養、年齢区分などを含めます。固有条件には組織形態、役員報酬、経費、法人固定費、事業構成などを含めます。

入力条件の差だけで比較結果が変わることを避けるため、画面には変更した項目と固定した項目を示します。端数処理・税率の適用順・税額控除等の扱いは税目ごとに記録します。

## 制度値の記録形式

将来コード化する税率・保険料率・上限・等級表には、次のメタデータを持たせます。

| 属性 | 内容 |
|---|---|
| 対象年度・適用期間 | 暦年または事業年度、施行・適用開始日 |
| 適用範囲 | 全国、都道府県、市区町村、加入制度など |
| 値・単位 | 比率、金額、等級、上限等 |
| 一次出典 | 公的機関のURLと資料名 |
| 確認日 | 人が一次情報を確認した日 |
| 判定状態 | 確認済み、要専門家レビュー、未確認、対象外 |
| テスト例 | 境界値と手計算できる例 |

出典が見つからない場合は値を推測で埋めず、「未確認」として利用者に表示するか、当該ケースの計算対象から外します。

## ケース別レビュー

制度値の入力レビューと、その値を計算に使う条件のレビューを分けます。例として、料率表そのものが公式資料に掲載されていても、複数業種を営む人への事業税区分や、個別企業の社会保険加入要件が自動で決まるとは限りません。

複雑なケースは、次の状態遷移で扱います。

1. **候補:** 利用者の要望として登録。
2. **調査中:** 一次資料と適用条件を特定。
3. **専門家レビュー待ち:** 個別解釈・制度横断の検証が必要。
4. **実装済み:** 仕様、出典、境界テストが揃った。
5. **継続監視:** 次回改正・料率変更を確認する担当と時期を登録。

## プライバシー

現行シミュレーターは個人の入力をブラウザ内で処理する方針です。入力値をサーバーへ送信・保存・ログ記録・解析へ連携しません。公開デモやIssueで共有する例には架空の値だけを使い、実在の税務書類・収入情報・個人情報を求めません。

## 限界

画面上の免責表示だけでは、個別ケースの誤差や法的な取扱いを解消できません。重要な制度判断や個人別の助言が必要な場合は、税理士・社会保険労務士等に確認してください。
